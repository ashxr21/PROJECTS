💸 Spendly — Expense Tracker



Spendly is a sleek, modern, and lightweight web application designed to help users take control of their personal finances. 
Built with HTML, CSS, and JavaScript, it provides a clean dashboard interface to track income, monitor expenses across categories, view spending breakdowns,
and manage monthly budgets—all without bloated frameworks.

✨ Features



Real-Time Financial Dashboard: Instant calculation and live updating of total balances, income, and expenses.


Dual Transaction Support: Seamlessly toggle and record both Income (with custom descriptions like allowances) and Expenses (with categorizations).


Category Management: Track spending across customizable categories including Food, Transportation, Shopping, Bills, Entertainment, Health, and Other.


Spending Breakdown: Automatically groups and aggregates expenses by category to visualize where your money is going.


Monthly Budget Tracking: Set, update, and monitor custom monthly budgets to keep your spending in check.


Interactive UI & Sidebar Navigation: Fully functional single-page layout switching between Dashboard, Transactions, Categories, and Settings views.


Responsive Design: Fully adaptable grid layout optimized for desktop, tablet, and mobile viewports.


🛠️ Tech Stack



HTML – Semantic structure and form elements.


CSS – Modern styling featuring Flexbox, CSS Grid, custom variables, and responsive media queries.


JavaScript (ES6+) – DOM manipulation, dynamic rendering, event handling, state management, and real-time calculations.
